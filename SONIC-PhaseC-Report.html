What the workflow found

Six agents: two gap-fill, four verifiers.

The aggregate result reported 15 violations and 12 deviations, but those numbers were heavily duplicated — animated box-shadow appeared three times, the cn() className rule five, the reduced-motion block four. De-duplicating gave 11 distinct defects, each re-checked against the source before anything changed.

The per-agent records also held detail the summary hid: each verifier returned its own findings and risks lists. Re-reading those against the tree turned up four more items still open, including the one bug in this batch that actually broke a daily interaction.

Fixed this round

The four items the aggregate report never surfaced.

Space stopped toggling playback when any button had focus

Fixed

The keyboard guard stood down for Space whenever focus was anywhere inside a <button>. With focus on a queue row's move arrow or a nav link, the app's primary shortcut silently did nothing. K still worked, so casual testing missed it.

The guard now yields only to buttons carrying a data-sonic-playpause marker, applied to the three real transport controls. Verified with eight behavioural cases, including children nested inside the transport button.

Playing ring had no scale on the cover

Fixed

F7 asks for a ring with a subtle scale on the cover. The ring was present but static, and its transition pointed at a no-op.

An outward scale would have been clipped by the tile's overflow-hidden, so the ring is inset and scaled to 0.97 instead — the only place the halo can be seen.

Skeleton measurement was documented wrong

Fixed

The comment claimed a 56px row box. The real arithmetic is min-h-12 (48px) plus py-1.5 twice (12px) = 60px. The behaviour was always correct — both skeleton and row resolve to 60px, so the delta is genuinely zero — but the number would mislead the next person checking the ≤2px target.

No-JS first paint: investigated, then deliberately left alone

Not changed

Adding .touch-visible to the play overlay looks like the obvious fix, but that utility emits opacity: 0 under (hover: hover) and would fight the opacity class the card emits for touch. Tailwind's output order, not intent, would decide the winner.

Applied, recognised the collision, reverted, documented. The overlay already opens visible, and a JS-disabled client cannot play the card at all — the affordance is moot rather than lost.

Fixed in the first pass

Seven defects from the aggregate report.

Animated box-shadow on the track card

Fixed

Interpolated every frame, which the spec forbids outright. The file's own comment claimed it never animated box-shadow — true of the ring, false of the card root.

Replaced with a pre-rendered layer whose opacity animates. It sits on the non-clipping wrapper at the tile's exact size, because inset-0 would have thrown a shadow under the title text.

An undefined CSS variable disabled a transition

Fixed

--dur-quick does not exist — only micro, standard, expressive and page are declared. The transition silently never ran. Invisible to typecheck and lint.

Reduced motion squashed the shimmer and marquee

Fixed

One grouped rule applied scaleY(0.6) to the equalizer bars and the skeleton gloss and title marquee. The block's own comment said it was bars-only.

A button role wrapped three real buttons

Fixed

The queue row was role="button" yet contained the play/pause toggle, move arrows and the overflow menu. Invalid ARIA — screen readers flatten interactive descendants.

The row is now a list item holding siblings: a decorative index, the toggle, and one labelled play button.

All artwork loaded lazily

Fixed

Including the mini-player thumbnail and the full-player hero — on screen at the moment a track changes, deferring the very art the viewer is looking at.

An opt-in eager prop keeps lazy loading for the long card shelves, where it genuinely saves bytes.

Dead code and off-budget durations

Fixed

An unused equalizer component and an orphaned keyframe removed. A 0.18s duration — not one of the four allowed values — replaced, and several hardcoded timings routed through the motion tokens.

Left open, on purpose

Each of these is a decision with a reason, not an oversight.

The player overlay re-renders four times a second

Open

progress lives in the broadcast player context, so the whole full-player overlay re-renders on every time-update. The spec states twice that only leaf components may subscribe to current time.

A real violation, but the fix means restructuring the context — which is shared-care and additive-only. That needs the proposal route rather than an improvised change. Benign while the overlay is closed.

About thirty className sites skip the helper

Open

The styling rule asks for cn() on every conditional className. It is used everywhere the upgrade touched code; roughly thirty untouched call sites still assemble template strings.

A real rule deviation. Converting untouched call sites is large diff noise for no runtime effect — recorded rather than done blind.

Toast timer edge cases

Open

Hovering then tabbing away can leave a focused toast's timer running, and a brief hover at the very start can extend a toast by up to half its life. Low impact; no harness exists to test toast timing.

Runtime behaviour no test can reach

Unverified

Long-press cancellation, drawer drag-to-dismiss competing with list scroll, and screen-reader behaviour on the restructured queue row. Playwright is absent from the repository, so these need a manual pass.

One note on method

Two findings in this batch were not code defects by the time they reached me: one agent had silenced a dead-code warning with an eslint suppression, which made an earlier lint run look clean while masking the problem, and one "no cache entry to evict" log line contradicted a working fix.

Both were chased down rather than accepted. The suppression was replaced by deleting the dead code; the log line turned out to come from a later request to an already-evicted key — correct behaviour, confirmed by reading the timestamps in order.

Also finished in this session, outside the workflow: a playback bug where songs failed to play on the second attempt. YouTube invalidates extracted stream URLs well before their advertised expiry, and the cache held them for four hours regardless. Fixed with a shorter TTL plus eviction keyed on the origin's own rejection — diagnosed by fetching a stale URL directly from the origin, which showed the proxy itself was innocent.
